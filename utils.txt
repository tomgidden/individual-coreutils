# GNU coreutils utilities built by this project.
#
# Full coreutils coverage: every utility coreutils 9.11 ships, minus the
# two below that macOS's own build can't produce at all. This project
# intentionally ships duplicates of tools macOS already has (ls, cp, mv,
# chmod, date, ...) as well as the genuine gaps -- unlike Homebrew's
# `brew install coreutils`, each one here is its own standalone
# download/binary with no shared runtime or package-manager dependency.
#
# Excluded, and why:
#   chcon, runcon -- gated on SELinux support in coreutils' own
#     configure.ac (only added to the build if a real <selinux/selinux.h>
#     is detected, or --with-selinux is passed). This project always
#     configures with --without-selinux (see build-tarball.sh /
#     build-git.sh), which is also the only sane choice on macOS -- there
#     is no SELinux to link against. `make src/chcon` simply has no
#     target in that configuration; these two aren't a "runs but does
#     nothing on macOS" case, they don't get built at all.
#
# One line per utility, comments with '#' allowed.
